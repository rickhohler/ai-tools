# Coding Style Preferences

This document captures our subjective choices for code formatting and style.

## Formatting
- **Indent**: 4 spaces (Python), 2 spaces (JS/TS/Flutter)
- **Quotes**: Double quotes preferred where possible
- **Commas**: Trailing commas in multi-line lists/dicts

## Structure
- **Imports**: Grouped by standard lib, 3rd party, local
- **Ordering**: Public methods before private
