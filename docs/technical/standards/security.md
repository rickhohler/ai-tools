# Security Policy

## Reporting a Vulnerability

**Do not report security vulnerabilities through public GitHub issues.**

Please report suspected security vulnerabilities by creating a private GitHub Security Advisory or emailing the maintainers directly. We aim to respond within 48 hours.

## Security Best Practices

1.  **Validate Input**: Always validate external input (files, network data) before processing.
2.  **Principle of Least Privilege**: Run processes and access files with minimum necessary permissions.
3.  **Error Handling**: Do not leak sensitive information in error messages.
4.  **Dependencies**: Keep dependencies updated to avoid known vulnerabilities.

## Disclosure Policy

When we receive a security bug report, we will:
1.  Confirm the problem.
2.  Prepare fixes for supported versions.
3.  Publish a security advisory once patches are available.
